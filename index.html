VERIFY PDF

Политика конфиденциальности

Дата вступления в силу: 15 октября 2026 г.

Verify PDF — расширение для локальной работы с PDF-файлами в браузере. Основной принцип продукта: документы пользователя обрабатываются на его устройстве и не загружаются на серверы Verify PDF.

1. Какие данные мы собираем

Verify PDF не собирает и не передаёт разработчику пользовательские данные. В частности, расширение не отправляет PDF-файлы, содержимое документов, названия файлов, изображения, подписи, историю просмотра, данные аутентификации, платёжные данные, медицинские данные или данные о местоположении.

2. Обработка документов

Операции с PDF и изображениями выполняются локально в браузере на устройстве пользователя. Файлы используются только для выполнения выбранной пользователем операции и не отправляются на серверы Verify PDF.

3. Локальные настройки

Расширение может хранить на устройстве пользователя отдельные настройки интерфейса, например выбранную тему, состояние подсказок и связанные с ними параметры. Эти настройки сохраняются локально в хранилище браузера и не передаются разработчику.

4. Обратная связь

Verify PDF не отправляет форму обратной связи самостоятельно. Если пользователь нажимает кнопку открытия готового письма в Gmail, расширение формирует текст обращения локально и открывает страницу создания письма Gmail только по явному действию пользователя.

В такое письмо не добавляются PDF-файлы, содержимое документов или названия загруженных файлов. Если пользователь сам указывает адрес для ответа, текст сообщения или иную информацию, дальнейшая обработка этих данных осуществляется выбранным им почтовым сервисом в соответствии с политикой этого сервиса.

5. Продажа и передача данных

Мы не продаём пользовательские данные и не передаём их третьим лицам для рекламы, кредитования, определения платёжеспособности или целей, не связанных с основной функциональностью продукта.

6. Удалённый код и аналитика

Verify PDF не загружает и не выполняет удалённый JavaScript или WebAssembly. В текущей версии расширения не используется собственная система аналитики, отправляющая данные разработчику.

7. Безопасность

Расширение спроектировано так, чтобы основная обработка документов происходила локально. Пользователь самостоятельно выбирает файлы и запускает операции над ними.

8. Изменения политики

При существенном изменении принципов обработки данных эта политика будет обновлена. Актуальная версия всегда будет размещаться по тому же публичному адресу.

9. Контакты

VERIFY PDF

Privacy Policy

Effective date: October 15, 2026

1. Data we collect

Verify PDF does not collect or transmit user data to the developer. The extension does not send PDF files, document contents, file names, images, signatures, browsing history, authentication data, financial data, medical data, or location data to Verify PDF servers.

2. Local document processing

PDF and image operations are performed locally in the user's browser on the user's device. Files are used only to perform the action selected by the user and are not uploaded to Verify PDF servers.

3. Local preferences

The extension may store interface preferences locally, such as the selected theme and tips settings. These preferences remain in browser local storage and are not transmitted to the developer.

4. Feedback

Verify PDF does not send feedback forms by itself. If the user chooses to open a prepared message in Gmail, the extension creates the feedback text locally and opens Gmail's compose page only after an explicit user action.

PDF files, document contents, and uploaded file names are not included in the prepared message. Any information voluntarily entered by the user is then handled by the user's chosen email provider under that provider's privacy policy.

5. Sale or sharing of data

We do not sell user data or share it with third parties for advertising, creditworthiness, lending, or purposes unrelated to the extension's core functionality.

6. Remote code and analytics

Verify PDF does not download or execute remote JavaScript or WebAssembly. The current version does not use developer-operated analytics that transmits user data to us.

Privacy and support inquiries: veryverify2026@gmail.com.
